# kangyonz.com 개편 — HANDOFF

작업 기준 문서. 새 대화에서 이어갈 때 이 파일부터 읽을 것.

## 구조 (중요)
- kangyonz.com 운영본 = moneypiee 저장소의 `scuba.html`(DTMD)을 `.github/workflows/sync.yml`이 10분마다 복사·배포.
- 이 저장소(KANGYONZ) 루트는 sync 때마다 지워짐. **`proto/` 폴더만 보존**(sync.yml에 예외 처리).
- 시안 주소: https://kangyonz.com/proto/ (목록), 작업본 https://kangyonz.com/proto/v3.html
- 시안은 localStorage·IndexedDB 이름 앞에 `proto_`를 붙여 실제 앱 데이터와 분리(v1). noindex.
- 버전 규칙: **확정 전까지 v3를 계속 덮어씀.** 새 번호는 사용자가 요청할 때만.
- 배포 확인: push 후 `sync.yml`을 workflow_dispatch로 실행하면 1~2분 안에 반영.

4. 앱 4개 (이름 없이 설명만, 아이콘은 명암만 남겨 남색→베이지(#b9ab98)→미색 3단, 감마 0.7 = 비교안 C. DTMD만 바탕 밝기를 다른 3개 중간값(0.53)에 맞춰 L'=0.24+0.76L로 끌어올림)
